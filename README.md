OTMusic 可以在 On-Together 房间内同步播放网易云音乐、Bilibili 视频音轨和音频直链。房间成员会跟随 DJ 的播放内容与进度，并根据自己和 DJ 的距离听到不同音量。

## 安装和使用

完整的安装和使用教程包含在 [Releases](https://github.com/qieqieWWW/OTMusic-Mod/releases) 的发布包内。

## 支持的音源

| 来源 | 输入格式 | 示例 |
| --- | --- | --- |
| 网易云音乐 | `n` + 歌曲 ID | `n3379792479` |
| Bilibili | `b` + BV 号或完整视频链接 | `bBV1rstb6dEr2` |
| 音频直链 | `u` + 完整 URL | `uhttps://example.com/audio.mp3` |

网易云 VIP、地区限制、版权限制和已下架内容遵循音源服务本身的访问结果，OTMusic 不绕过账号权限。
